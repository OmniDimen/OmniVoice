OmniVoiceby Lucas

用你自己的 OpenAI 格式 TTS 接口接管 ChatGPT 朗读；任意网页选中文本也能朗读。

接口OpenAI 格式 /v1/audio/speech

语种与情感给 GPT-SoVITS 这类接口用

发送 other_params 附加层 GPT-SoVITS 的 GSVI 接口需要打开；接标准 OpenAI 或普通中转时关掉。
把 API Key 同时写进 other_params.app_key GSVI 的密钥不在请求头里，而在这个字段；用别的服务可以关掉。

交互

替换 ChatGPT 网页的朗读 点页面里的朗读按钮时，把整页静音，改用这里的接口播放同一条消息。
选中文本后显示「朗读」小按钮 所有网页生效，包括 ChatGPT。
