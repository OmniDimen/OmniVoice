# OmniVoice

用你自己的 TTS 接管 ChatGPT 的朗读。

Chrome / Edge 扩展（Manifest V3）。点 ChatGPT 网页里的「朗读」按钮时，它会把网页原声静音，改用你配置的 OpenAI 格式 TTS 接口来读这条消息；在任意网页选中一段文字，也能直接朗读。

作者：[Lucas](https://github.com/lucas-nous) · License: MIT

---

## 为什么做这个

ChatGPT 自带的朗读音色固定，也不能换成自己部署的模型。而大多数 TTS 服务都提供了 OpenAI 格式的 `/v1/audio/speech` 接口——把这一层接管下来，用哪个音色、哪套模型，就完全由你决定。

## 功能

- **接管 ChatGPT 朗读**：点页面里的朗读按钮，静音网页原声，改用自己的接口读这条消息的正文。
- **选中即读**：选中任意网页的文字，浮出「朗读」小按钮；右键菜单也能触发。
- **播放控制**：右下角胶囊，可暂停 / 继续 / 停止 / 调倍速。
- **长文分段**：按句子切分，边合成边播，不等整段返回；同一段文本本地缓存，重复点击不重复请求。
- **可移植**：只要接口兼容 OpenAI 的 `/v1/audio/speech`，OpenAI 官方、第三方中转、本地推理服务都能接。
- **自带诊断**：抓不到正文时，设置页会记录按钮标签、祖先链、页面结构快照，方便定位页面改版。

## 安装

1. 下载或克隆本仓库到本地。
2. 浏览器地址栏输入 `chrome://extensions`（Edge 用 `edge://extensions`）。
3. 打开右上角的「开发人员模式」。
4. 点「加载解压缩的扩展」，选择本仓库根目录（含 `manifest.json` 的那一层）。
5. 点工具栏上的 OmniVoice 图标，打开设置页。

## 配置

### 接 OpenAI 官方

| 字段 | 值 |
| --- | --- |
| 接口地址 | `https://api.openai.com/v1/audio/speech` |
| API Key | 你自己的 Key |
| 模型 | `gpt-4o-mini-tts` |
| 音色 | `alloy`（也可用 nova / shimmer / echo / fable / onyx 等） |
| 返回格式 | mp3 |
| 附加层 `other_params` | 关闭 |
| Key 写入请求体 | 关闭 |

填完点「试听一句」确认能出声。

### 接自建服务（GPT-SoVITS / GSVI 等）

这类服务的密钥不走请求头，而是放在请求体的 `other_params` 里，所以要额外打开两个开关：

| 字段 | 值 |
| --- | --- |
| 接口地址 | `http://127.0.0.1:8000/v1/audio/speech` |
| 模型 | 服务里的模型名，如 `GSVI-v2ProPlus` |
| 音色 | 服务里的音色名，如 `Cove` |
| 语种 text_lang | 中英混合 |
| 参考音频语种 prompt_lang | 中文 |
| 情感 emotion | 默认 |
| 附加层 `other_params` | **打开** |
| Key 写入请求体 | **打开** |

「附加参数 JSON」可以往 `other_params` 里塞任意字段，比如：

```json
{ "top_k": 10, "temperature": 1 }
```

### 其他

- **单段字数上限**：默认 120。接口有输入长度限制时调小，本地服务可以调大。
- **语速**：接口侧的 `speed` 参数；播放器上的倍速只作用于本地播放，不再请求接口。

## 工作原理

1. 内容脚本捕获 ChatGPT 朗读按钮的点击，在页面里就地定位这条消息的正文容器（四路兜底：页面标记 → 向上查找 → 坐标打点 → 最近正文块）。
2. 后台立即把整个标签页静音，避免原声漏出。
3. 文本按句切段，逐段请求 `/v1/audio/speech`，在离屏文档（offscreen document）里播放。
4. 播放结束时先确认标签页真的没有声音了，再解除静音；如果本体还在响，播放器上会出现「恢复声音」按钮，由你决定何时放开。

之所以不拦截 ChatGPT 的音频请求，而是整页静音：它的播放状态、进度、按钮文案都由自己的音频驱动，掐掉请求容易让界面卡在「播放中」，静音则完全不影响它的逻辑。

## 已知限制

- ChatGPT 的页面结构随时可能改版。改版后如果抓不到正文，扩展会提示「没抓到正文」，请把设置页最下方的诊断信息贴到 issue 里。
- 静音期间 ChatGPT 自己仍在请求并播放音频，只是听不见，会消耗它自己的额度。
- 代码块、表格、链接地址默认跳过，只读正文。数学公式（KaTeX）也不读。
- 只在 Chromium 内核测试过，Firefox / Safari 未适配。

## 隐私

- 所有配置只存在浏览器的 `chrome.storage.local`，不上传任何服务器。
- 需要朗读的文本会发送到你自己配置的接口地址，扩展本身不收集、不留存。
- 没有统计、没有埋点、没有第三方请求。

```
├── background.js        # 会话、静音、离屏调度

├── content/content.js   # 页面 UI、选中朗读、ChatGPT 正文定位
├── options.html/js      # 设置页与诊断面板

```
